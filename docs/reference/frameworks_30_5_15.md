## 預設內建安裝建議

**建議預裝的基礎套件**：先以 Reasona 自有的工具註冊／權限閘、JSON Schema 驗證、審計事件及薄 adapter contract 為核心；這些是產品層設計建議，不代表已有相關套件。確認後端 runtime 後只選一個輕量 Agent runtime：Python 後端可評估 [PydanticAI（MIT）](https://github.com/pydantic/pydantic-ai)；TypeScript/Node 後端可評估 [Vercel AI SDK（Apache-2.0）](https://github.com/vercel/ai)。後端語言尚未確認時，不應預裝任一語言專屬框架；也不建議同時納入多個 Agent framework。模型 provider 預設保持未配置，不會因安裝套件而呼叫外部服務。

**MCP 僅按需安裝**：[MCP Python SDK（MIT）](https://github.com/modelcontextprotocol/python-sdk) 或 [MCP TypeScript SDK（混合授權）](https://github.com/modelcontextprotocol/typescript-sdk) 只在 Reasona 明確支援 MCP 後作為 adapter；不得預設連接、啟動或授權任何 MCP server。這些是條件式安裝建議，不是已安裝狀態。此文件只提出建議，**本次沒有安裝任何套件、啟動服務或執行候選程式**。

**重量級平台、模型供應商及雲端整合**應以 adapter 或獨立服務呈現，完成設定後才安裝/啟用：Dify、AutoGPT Platform、Letta、Agno、OpenHands 等需資料庫、容器或多服務者；Composio、E2B、Browser Use Cloud、遠端 MCP、Temporal/Redis/向量庫及雲端模型亦同。安裝前固定版本，確認目標 repo 是否 redirect/封存、檢查 repo 與子目錄授權、依賴、資料流、網路出口與費用/服務條款；任何 `NOASSERTION`、混合授權、Polyform Shield、modified Apache、enterprise source-available 功能都必須 license review。執行任意程式、shell、Python、瀏覽器或桌面動作的候選須 security review，並在獨立 sandbox/container/VM 中以最小權限運作。

**必須由使用者明確授權**的項目包括：所選模型供應商與資料傳送；外部帳戶 OAuth/API scope；MCP server/connector 的 endpoint、命令、網路及其每一個 tool；讀寫檔案、shell/Python/code interpreter、瀏覽器 profile/cookies、表單提交或任何會產生副作用的操作；以及可能付費的託管服務。未授權的 shell、Python、browser、code execution 預設不可執行；不得因已連上 MCP server 就推定其工具皆獲准。MCP 工具必須逐工具白名單並在每次高風險/寫入操作前取得使用者確認。

Reasona 應由應用本身持有權限決策：框架只能提出 tool call，不能自行擴權；每個子代理繼承明確、最小且可撤銷的工具集合，並共用單一 subagent 數量、遞迴深度、總步數、時間與 token/cost budget。對話/工作進度保存需明確選擇 persistence backend、保留期限、刪除與租戶隔離策略；恢復任務時再次驗證授權，而非永久沿用舊同意。高風險和外部副作用採 human approval；工具輸入、網頁/MCP 回傳內容皆視為不可信資料並做 prompt-injection 隔離。不得自動掃描本機檔案系統；只在使用者選定的檔案/目錄、明確列出的網域與工具範圍內工作。
